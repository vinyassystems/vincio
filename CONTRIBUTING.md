# Contributing to Vincio ⚡

First off, thank you for considering contributing to **Vincio**! It's people like you that make Vincio such a great tool for developers around the world.

## 🚀 How Can You Contribute?

### 1. Star & Share
- Give this repository a ⭐ **Star** on GitHub to support our work and help more developers discover Vincio!
- Share Vincio on Twitter / X, Reddit (`r/selfhosted`, `r/webdev`), and LinkedIn.

### 2. Reporting Bugs
- Search existing issues to ensure the bug hasn't already been reported.
- Open a new issue with a clear title and description, including OS, Node.js version, and steps to reproduce.

### 3. Suggesting Features
- We love feature suggestions! Please submit an issue labeled `enhancement` describing the use case and why it would benefit the community.

### 4. Code Contributions
1. **Fork** the repository on GitHub.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/<your-username>/vincio.git
   cd vincio
   ```
3. Create a descriptive feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. Install dependencies:
   ```bash
   npm install
   ```
5. Test your changes locally:
   ```bash
   npm start
   ```
6. Commit your changes with clear commit messages:
   ```bash
   git commit -m "feat: add support for inline AI completions"
   ```
7. Push to your fork and submit a **Pull Request** to `main`!

## 📜 Code of Conduct
Please be respectful, collaborative, and constructive when interacting in issues and pull requests.

Thank you for building the future of open-source collaborative workspaces with us!
